# Contenu de Brioo

Ce dépôt contient le contenu pédagogique de l'application **Brioo** (révision hors ligne
pour les élèves de Guinée). L'application télécharge `manifest.json` puis uniquement les
matières dont la version a changé.

- `packs/` : une matière par fichier (leçons, fiches, activités).
- `admin/` : le tableau de bord pour modifier le contenu (GitHub Pages).

Ne modifie pas les fichiers à la main : utilise le tableau de bord admin, qui vérifie
le format et met à jour les versions automatiquement.
